# Changelog

## NOVA 2.0.0
- Added a dedicated, dependency-light `core.py` module and unit tests.
- Added flashcard study mode.
- Added true plain-text export and JSON conversation backup alongside Markdown.
- Added clear-conversation action.
- Strengthened upload signatures with SHA-256 content hashes to detect same-name/same-size file changes.
- Added dark neon Streamlit theme config, environment-variable template, gitignore, and expanded installation/privacy/testing documentation.
- Improved assistant instructions to distinguish evidence from inference and flag uncertainty.
